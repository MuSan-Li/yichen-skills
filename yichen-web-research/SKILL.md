# 逸尘互联网研究

用户自有的研究总入口：判断任务阶段、编排子 Skill、守住跨阶段授权门，并提供横纵研究协议与离线体检。它不包装任何单一后端；各阶段的参数、限额、后端选择和登录态规则只以下游当前 `SKILL.md` 为准，本文不复制。

## 何时使用总入口

仅在以下情况使用本 Skill：

- 请求跨越两个以上阶段，例如“先搜索，再选出并归档来源”。
- 请求跨越多个平台且不止搜索，还需要候选确认、归档、转写或后续分析。
- 用户只描述研究目标，尚未指定搜索、归档或收藏导出。
- 需要先体检多个后端，再决定安全可用路线。
- 用户明确要求横纵分析、发展史与当前格局交叉、竞品或行业全景，以及有来源约束的系统深度研究。

单阶段搜索无论涉及一个还是多个平台，都直接进入 `$yichen-unified-search`；“跨平台”本身不是触发总路由的充分条件。其他单一动作同样直接进入下表对应 Skill。

路由后先完整读取目标 Skill 的当前文件 `${YICHEN_SKILLS_ROOT:-$HOME/.agents/skills}/<Skill 名>/SKILL.md`，再按其中的规则执行。

## 多阶段流程

```text
研究目标
  -> yichen-unified-search
  -> 标准候选清单
  -> 是否由用户明确要求归档且范围已经限定？
       ├─ 否：返回候选，或继续获准的原文核验与分析
       └─ 是：yichen-content-archive
              -> 按需交给 yichen-asr、视觉分析或知识库 Skill
```

1. 固定研究目标、阶段、平台与用户已明确的动作范围；跨平台、多后端或登录态任务先运行下文体检。
2. 每个阶段按目标 Skill 执行，阶段之间只传标准交接：搜索层 `{schema_version, request, routes, candidates, coverage, errors}`，归档层按 `$yichen-content-archive` 的交接契约。
3. 搜索候选只是线索；综合结论前打开原文核验具体主张。
4. 交付时说明各阶段覆盖、失败、截断、日期与登录态限制，不宣称穷尽。

## 横纵研究模式

仅在任务同时需要历史演进、当前横向结构与综合判断时使用。进入该模式后，完整读取 [执行契约](references/hengzong-execution-contract.md) 和其中指向的研究参考，再运行离线计划器与证据整理器。地域/语言覆盖、时间资格、证据定位、缺口披露与正式报告就绪门均保留；单一查证或快速总结不进入该模式。

本模式基于、受启发并扩展 KKKKhazix/khazix-skills 的 `hv-analysis`，作者为数字生命卡兹克，固定参考上游提交 `7a5c4934be4106ac740ffdb95280bb81b3f4b83c`。完整归属与 MIT 许可见仓库根目录 `THIRD_PARTY_NOTICES.md` 及 `licenses/KKKKhazix-khazix-skills-LICENSE.txt`。

## 授权边界

1. 仅在用户明确要求归档且范围已限定时进入 `$yichen-content-archive`。搜索结束后不得自动归档或下载；收藏导出结束后也不得自动读取正文或下载媒体。归档与下载都需要独立、明确的当轮请求。
2. 交接文件、候选清单、研究计划和体检结果都不产生或转移授权；后端已安装或浏览器已登录也不产生授权。登录态、私人收藏/书签/Feed、账号后台、付费 API 与媒体下载，分别按目标 Skill 的授权门执行。
3. 所有社交平台保持只读：不发帖、不评论、不点赞、不收藏、不关注、不私信，不改变账号状态。绝对不得操控微信桌面端或移动端 UI。
4. 不得绕过验证码、登录墙、付费墙、限流、地区限制或访问控制；不打印或保存 Cookie、Token、API Key、登录凭证及敏感 URL 参数。
5. 有界站点 Map 与归档只在用户明确给出公开站点的路径、页数和深度范围时进行；Map 只产候选，不能自动跨过确认门进入归档。
6. 付费 API 或可能产生显著额度消耗的批量转写，执行前说明范围和预计数量。
7. 不覆盖既有产物，不自动删除临时文件；任何清理都须先获用户明确允许，并且只能移入废纸篓。

## 唯一入口与子 Skill 调用

- 本 Skill 是唯一的互联网研究总入口，不保留旧名称兼容入口。“横纵研究”是本入口的显式研究协议，不新增 `yichen-unified-research` 兼容入口，也不改变 `$yichen-unified-search` 的候选搜索职责。
- 子 Skill 是独立的执行规则，不是可递归调用的函数。路由后直接按目标 Skill 执行，目标 Skill 不得再回到本总入口。
- 若子 Skill、必要后端、登录态或额度不可用，如实报告具体缺口；不得把“已经正确路由”表述成“外部平台必然成功”。
